Setup Backend Google Apps Script (Database)

Langkah Sinkronisasi Google Sheets (Pasti Berhasil):

  1. Buka Google Sheets dan buat Spreadsheet Baru (nama bebas).
  2. Klik menu Ekstensi > Apps Script di bagian atas.
  3. Hapus seluruh isi script lama, lalu tempelkan kode Code.gs di bawah ini.
  4. Langkah Kunci: Di bagian atas editor Apps Script, pilih fungsi initialSetup pada dropdown fungsi, lalu klik tombol Run (Jalankan).
  5. Setujui perizinan (*Review Permissions > Select Account > Advanced > Go to Untitled (unsafe) > Allow*).
  6. Klik tombol Deploy > Deploy Baru -> Pilih Jenis: Web App.
  7. Atur Execute as: Me dan Who has access: Anyone (Siapa Saja).
  8. Salin URL Web App yang dihasilkan, lalu masukkan pada kolom di bawah.
